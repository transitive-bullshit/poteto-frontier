# The Poteto Frontier

Where do you land between one closely watched agent and thousands of agents you trust?

A tiny React app inspired by [Lauren Tan’s chart](https://x.com/poteto). Add your X photo, drag yourself along the curve, and download your chart as a Takumi-rendered PNG.

To get started, ask an agent: “Read AGENTS.md and contributing.md, install with pnpm, and start this app.”
